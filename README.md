# Category-City Wise Sales Analysis | Microsoft Excel

## Project Overview
An Excel-based sales analysis project designed to explore business performance across product categories and cities.

## Objectives
- Analyze sales performance across product categories.
- Compare sales across different cities and regions.
- Examine revenue, cost, profit, and profit margin.
- Present key business metrics through an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel data analysis and visualization features

*Update the tools list to reflect the features actually used in the workbook.*

## Workbook Structure
- **DATASET:** Raw sales records containing order dates, regions, states, cities, product categories, and sales-related fields.
- **REPORTS:** Summary reports and business metrics.
- **DASHBOARD:** Visual representation of sales performance.

## Key Metrics
- Total Revenue
- Total Cost
- Total Profit
- Profit Margin

1. Download the Excel workbook from this repository.

4. Explore the sales performance metrics and visualizations.
